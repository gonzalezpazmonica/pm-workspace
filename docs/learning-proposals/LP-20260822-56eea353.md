# Learning Proposal LP-20260822-56eea353

## Origen

bug detectado en SCL-009 2026-08-22: urllib.request.urlopen(url, headers=...) falla en Python 3.12 (TypeError) — solo el Request acepta headers

## Evidencia

scripts/federation-discover.sh:tests/test-scl-009-autodiscover.bats

## Diagnóstico

El health-check del FederationRegistry usaba urlopen con headers como kwarg, valido en 3.9 pero TypeError en 3.12, cayendo al except y marcando toda instancia unhealthy. El AC-02 del test BATS lo revelo despues de que el test colgara por un mock mal gestionado, no por el assert.

## Cambio propuesto

Para llamadas HTTP con headers en python: construir urllib.request.Request; nunca pasar headers como kwarg de urlopen. Al testear mocks HTTP en bats, usar procesos timeout standalone con teardown pkill, no heredocs en background.
