## Diagnóstico

Al implementar SCL-012, el commit se ejecuto estando en main (violacion de autonomous-safety: commits solo en ramas agent/*). La correccion fue branch + git reset --soft origin/main + recomit en la rama. Coste: una correccion extra, riesgo de dejar main con contenido no aprobado.

## Cambio propuesto

Regla de proceso: antes de cualquier commit, verificar git branch --show-current; si no hay rama agent/* propia, crearla ANTES de tocar el arbol, no despues del commit. En sesiones largas con muchos PRs, comprobar la rama actual en cada ciclo.
