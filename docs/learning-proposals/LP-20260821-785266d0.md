# Learning Proposal LP-20260821-785266d0

## Origen

Leccion de ingenieria del bucle SCL-001: cuando un sistema de mejora continua
se retroalimenta usando al propio LLM como juez de sus outputs, la senal de
aprendizaje es circular (el modelo valida su propio trabajo). La alternativa
verificada es usar un auditor determinista independiente como fuente de la
senal de error.

## Evidencia

labs/results/l11-sagi-result.md (repo local privado)
labs/experiments/l11-sagi-run2.md (repo local privado)

## Diagnóstico

El patron auditor-determinista → learning proposal → recall → re-generacion
produce mejora monotona en un bucle de calidad: en cada iteracion el algoritmo
detecta las carencias reales (auditor, no LLM), las persiste como learning
proposal y las inyecta via recall en la siguiente generacion. El mismo LLM sin
el algoritmo no mejora entre iteraciones. La variable que produce la
convergencia es el algoritmo y su senal determinista, no el modelo.

## Cambio propuesto

Regla: cualquier fix-loop en Savia debe usar un auditor determinista como senal
de aprendizaje (nunca el LLM como juez de si mismo), persistir la carencia como
learning proposal e inyectarla via recall. El patron es candidato a guard
reusable fuera de los experimentos.
