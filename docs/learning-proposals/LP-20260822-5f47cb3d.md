# Learning Proposal LP-20260822-5f47cb3d

## Origen

drift de numeracion 2026-08-22: labs/specs/ usa SE-335 y SE-336 para specs SAGI, colisionando con SE-335/SE-336 merged en main (prioridad descubrimiento, Turn-SDLC)

## Evidencia

labs/specs/SE-335-sagi-orchestrator.spec.md:labs/specs/SE-336-sagi-pruebas.spec.md

## Diagnóstico

El espacio SE-### numerico es global y ya fue consumido por specs de produccion. Labs usa SE-### sin reservar numeros, generando colision. Cuando una linea de investigacion se propone pasar a produccion (H5 SAGI), los numeros colisionados bloquean la trazabilidad.

## Cambio propuesto

Renumerar las specs SAGI de labs a SCL-011 (orquestador) y SCL-012 (pruebas P1-P5), alineado con el prefijo del programa SCL. El roadmap SAGI (docs/sagi-roadmap.md H5) se beneficia de numeros estables: SCL-011 = orquestador, SCL-012 = pruebas.
