# Dominio: selección de marcos GRC

## Por qué existe esta skill

La aplicabilidad cambia con jurisdicción, sector, producto y fecha. El router evita confundir obligación legal, compromiso contractual y buena práctica.

## Conceptos

- Framework: conjunto versionado de requisitos o recomendaciones.
- Requirement: referencia puntual a obligación o compromiso, validada por fuente.
- Applicability: decisión contextual revisable, no inferencia universal.

## Límites y confidencialidad

No almacena textos íntegros de normas protegidas ni datos del cliente en el repositorio público. La interpretación jurídica y las excepciones requieren revisión competente.
