# savia-labs — Domain knowledge

## Origin

Savia Labs nace como cupula de investigacion epistemica dentro de SaviaVaults
(SE-291). Aplica metodo cientifico a capacidades de agentes de IA.

## Como funciona

1. Preregistro obligatorio: toda hipotesis se registra antes de ejecutar
2. Resultados negativos de primera clase
3. Reproducibilidad: modelo, revision, semilla, hash
4. Validacion humana: descubrimiento maquina, validacion humano
5. Presupuesto por ciclo: tokens y horas declarados

## Lineas de investigacion

- L1: Divergencia grafo-modelo predice error
- L2: Certificados de ignorancia estructurada
- L3: Preguntas cross-dominio
- L4: Brecha capacidad-despliegue
- L5: Divergencia federada
- L6: Busqueda por diversidad

## Output

Resultados internos para mejora de agentes. No se publican externamente.

## Integracion

- Vault: labs/ en SaviaLabs
- Comandos: /labs preregister, /labs hypotheses, /labs results
