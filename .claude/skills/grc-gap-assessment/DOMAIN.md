# Dominio: evaluación preliminar GRC

## Por qué existe esta skill

Los informes de cumplimiento necesitan conectar cada estado con requisito, control y prueba. Esta skill produce una matriz revisable y conserva las decisiones humanas.

## Conceptos

- Finding: hallazgo borrador con referencia a prueba adversa.
- Risk: escenario y tratamiento propuestos, sujetos a propietario.
- Compliance matrix: estados por requisito y control dentro de un alcance.

## Límites y confidencialidad

No emite certificaciones, aprobaciones ni cierres oficiales. Los informes con datos de cliente se guardan fuera del repositorio público.
