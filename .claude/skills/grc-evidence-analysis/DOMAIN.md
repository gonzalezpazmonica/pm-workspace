# Dominio: evidencia GRC

## Por qué existe esta skill

Un documento puede existir sin probar que un control opera. Esta skill exige procedencia, periodo, alcance y prueba del aspecto evaluado.

## Conceptos

- Provenance: ruta, custodio, fechas, hash y método de captura.
- Trust level: confianza de una verificación externa al modelo.
- Contradicción: pruebas favorables y adversas que requieren resolución.

## Límites y confidencialidad

El hash local no demuestra autenticidad. Las evidencias reales de cliente permanecen en almacenamiento privado, fuera del repositorio público.
